# Controle de Gastos

Aplicação web para gerenciamento de receitas e despesas pessoais, desenvolvida com HTML, CSS e JavaScript puro.

O objetivo do projeto é facilitar o acompanhamento financeiro mensal por meio de lançamentos, resumo de saldo e visualização das despesas por categoria.

## Funcionalidades

- Cadastro de receitas e despesas.
- Organização dos lançamentos por mês.
- Visualização do saldo, das receitas e das despesas.
- Gráfico de despesas por categoria.
- Exportação dos lançamentos para CSV.
- Validação de dados e mensagens de erro.
- Armazenamento dos dados no navegador.
- Interface responsiva.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Node.js para execução dos testes automatizados

## Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/AlvaroSakaue7/Controle-de-gastos.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd Controle-de-gastos/controle-de-gastos
   ```

3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências para utilizar a aplicação no navegador.

## Testes

Para executar os testes automatizados, instale o Node.js 18 ou superior e execute:

```bash
npm test
```
